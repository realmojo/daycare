# daycare.keywordegg.com

전국 **어린이집**을 시군구·시설별로 보여주는 사이트.
yoyang·sanhu·medifee·vet·apt 와 같은 스택(Next.js + Supabase + Cloudflare)과
같은 UI 스킨을 쓴다.

---

## 주축 지표 — 교사 1인당 아동 수

원본에 정원수·현원수·**보육교직원수**가 있다. 여기서 학부모가 실제로 궁금해하는
숫자가 나온다.

```
교사 1인당 아동 수 = 현원 ÷ 보육교직원수
충원율             = 현원 ÷ 정원
```

어디서도 나란히 놓고 보여주지 않는데 어린이집을 고르는 가장 실질적인 기준이다.
medifee 의 ㎡당, apt 의 ㎡당과 같은 역할을 한다.

### 반드시 밝힐 것

**이 값은 법정 교사 대 아동 비율이 아니다.** 분모인 보육교직원수에 원장·조리원·
사무원이 함께 들어간다. 담임교사만 센 값이 아니므로, 낮다고 법을 지킨 것도
높다고 어긴 것도 아니다.

안 밝히면 **"이 어린이집은 법을 어겼다"** 는 잘못된 결론으로 간다.
`lib/daycare-data.ts` 주석, `DataNotice`, 시설 상세, 지역 표에 모두 적어 두었다.
지우지 말 것.

## URL 구조

| 경로 | 화면 |
|---|---|
| `/` | 홈 |
| `/지역` | 지역 허브 (시도별 시군구) |
| `/서울-강남구` | 지역 상세 — 어린이집별 교사 1인당 아동 수 |
| `/서울-강남구/햇살어린이집-a1b2c3d4e5f6a7b8` | **시설 상세 — 주축** |
| `/about` `/contact` `/privacy` `/terms` | 안내 |

**Next 16 은 라우트 파라미터를 자동 디코딩하지 않는다.** 한글 슬러그가 퍼센트
인코딩된 채로 넘어오므로 `lib/slug.ts` 의 `decodeSlug` 를 반드시 거쳐야 한다.
빼먹으면 한글 경로가 전부 404 가 된다.

시설 슬러그는 **이름 + center_id**다. 원본에 어린이집 코드가 없어서 적재
스크립트가 시도+시군구+이름+주소로 해시를 만든다. 조회는 꼬리로만 하므로 이름이
바뀌어도 옛 주소가 안 깨진다.

## 데이터

한국사회보장정보원 「어린이집 기본정보 조회(정기)」 · **기준일 2026-07-31**
· 전국 **25,595곳**

오픈API([3065251](https://www.data.go.kr/data/3065251/openapi.do),
[15013108](https://www.data.go.kr/data/15013108/standard.do) 등)가 있지만
활용신청이 걸려 있어, [정보공개포털](https://info.childcare.go.kr/)에서 시도별로
내려받은 xls 를 쓴다. 정기 갱신 자료라 자주 돌릴 이유도 없다.

```bash
npm run import:centers -- --dir ~/Downloads
npm run import:centers -- --dir ~/Downloads --dry-run
```

### 원본에서 걸린 것 넷

1. **같은 파일이 여러 번 받아진다.** 파일명에 (1)(2)… 가 붙는데 충북·경남·
   인천·세종이 두 번씩 있었다(4,170행). 행 전체를 키로 잡아 거른다.

2. **시도가 합쳐져 온다.** `전남광주통합특별시` 하나에 광주·전남이 같이 들어
   있고 각각의 표기는 아예 없다. 시군구 이름으로 가른다 — 전남에는
   동/서/남/북/광산구가 없어 겹치지 않는다. (apt 의 K-apt 도 똑같았다)

3. **경남에 이상한 표기가 섞인다.** `김해시장유출장소`(79곳)는 시로 올리고,
   `마산시(구)`·`진해시(구)`는 2010년 통합된 창원시로 바꾼다.

4. **center_id 를 정규화된 값으로 만들면 안 된다.** 규칙을 고치자 키가 바뀌어
   옛 행이 고아로 남았다(4개 지역). **원본 값**으로 만들고, 파일 전량을 받는
   방식이므로 **전량 교체**한다(폐지된 곳이 남지 않는다).

셋 다 조용히 어긋나는 종류라, 못 알아본 값은 경고로 찍고 넘어가지 않는다.
적재 뒤 `regions.json` 과 대조해 불일치가 0인지 확인할 것.

## 공개 판정 — isPublishable

시설이 있다는 것과 **보여줄 값이 있다는 것은 다르다.** 지역 중간값은 표본
**10곳 이상**일 때만 내보낸다(집계 함수가 null 로 만든다). 화면·사이트맵·
메타데이터가 모두 `isPublishable()` 하나로 판정한다 — 한 곳만 다르면 빈
페이지가 색인된다.

## 개발

```bash
npm install
npm run dev
npm run lint && npm run build
npx wrangler login && npm run cf:deploy
```

Supabase 는 keywordegg 계열과 같은 프로젝트를 쓰고 테이블 접두사(`daycare_`)로만
나눈다. 애드센스 퍼블리셔도 같은 계정이라 재승인이 필요 없다.
슬롯은 이 사이트용으로 새로 만들어 `lib/ads.ts` 에 채운다(지금은 빈 문자열이라
미노출).

**package-lock.json 을 다른 사이트에서 복사하지 말 것.** apt 에서 그렇게 했다가
Cloudflare 빌드가 `npm ci` 에서 깨졌다.
